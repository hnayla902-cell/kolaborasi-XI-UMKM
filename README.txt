CARA PASANG (XAMPP / Laragon)
1. Salin folder "ohara-bakery" ke htdocs (XAMPP) atau www (Laragon).
2. Buka http://localhost/phpmyadmin -> tab Import -> pilih database.sql -> Go.
3. Cek config.php (user/password database, nomor WhatsApp, rekening).
4. Buka http://localhost/ohara-bakery/
5. Admin: http://localhost/ohara-bakery/admin/login.php
   Username: admin | Password: ohara123 (ganti di config.php)
Foto produk: upload lewat dashboard admin. Jika belum ada, website memakai foto stok otomatis (butuh internet).
